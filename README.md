# Aviary

**Aviary** is a Java + Processing application that simulates swarm intelligence in structured populations.

## Overview

This software models how agent-based systems—such as ant colonies—collaborate to perform team tasks through decentralized communication. Agents operate independently and are "blind" (don't have information about their surroundings) but share information locally and with a central base, allowing them to collectively form paths between a base and a resource.

## Key Features

- Simulates swarm behavior inspired by natural systems (e.g., ants).
- Agents share information with nearby agents and a central base.
- Models the emergent formation of optimal paths between a base and a resource.
- Built with Java for logic and Processing for visualization.

## Purpose

The simulation helps visualize how local agent interactions can lead to efficient collective behavior in structured populations, supporting research in:

- Distributed systems
- Swarm robotics
- Collective decision-making
- Bio-inspired algorithms
